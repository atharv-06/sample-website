# ☕ Cafe Zarin – Irani Cafe Website

A modern and responsive website for **Cafe Zarin**, an Irani-style cafe.

The website provides information about the cafe, menu items, gallery, guest reviews, visiting hours, and table reservation functionality.

---

## 📌 Project Overview

Cafe Zarin is a frontend web project designed to provide a simple and attractive online presence for a local cafe.

The website focuses on:

- Cafe introduction
- Food and beverage menu
- Interactive menu categories
- Cafe gallery
- Customer notes/reviews
- Visiting information
- Table reservation form
- Responsive design for different screen sizes

---

## ✨ Features

### 🏠 Home / Hero Section
- Cafe branding
- Introduction to Cafe Zarin
- Opening hours
- Featured Irani Chai section
- Smooth navigation buttons

### 🍽️ Menu
The menu is divided into three categories:

- **Chai & Bakes**
- **Snacks**
- **Meals**

Users can switch between categories using interactive tabs.

### 🖼️ Gallery
The gallery includes categories such as:

- All
- Interior
- Food
- People

Users can filter gallery items based on category.

### 💬 Guest Book
Displays customer notes and reviews about the cafe.

### 📍 Visit Us
Provides:

- Cafe location
- Opening hours
- Simple map-style section
- Contact information

### 🪑 Table Reservation
Users can enter:

- Name
- Phone number
- Date
- Time
- Number of guests

After submitting the form, a confirmation message is displayed.

### 📱 Responsive Design
The website adapts to:

- Desktop
- Laptop
- Tablet
- Mobile devices
